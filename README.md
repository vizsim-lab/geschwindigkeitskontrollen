# Geschwindigkeitskontrollen (Berlin, Aachen)

Interaktive Karte der Geschwindigkeitskontrollen in **Berlin (2017–2019)** und **Aachen
(seit 2020)** – Neubau von [vizsim/geschwindigkeitskontrollen](https://github.com/vizsim/geschwindigkeitskontrollen)
mit genauerer Verortung und einer MapLibre-Karte im Stil der
[Unfallkarte](https://github.com/vizsim/unfallkarte).
